一箭又一箭 - 箭头解谜游戏

项目名称:
一箭又一箭（Arrow Puzzle Game）
游戏简介:
本项目是基于 Python 开发的点击式箭头解谜游戏，还原了《一箭又一箭》的核心玩法。
游戏棋盘为 5×5 网格，包含上、下、左、右四种方向的箭头。玩家需要观察箭头的方向与相互阻挡关系，按照正确的顺序点击箭头，使路径无阻挡的箭头飞出棋盘并消除。
每关设置 3 次失误机会，点击被阻挡的箭头会触发碰撞反馈并扣除 1 次失误次数，失误次数耗尽则本关失败；清空本关全部箭头即可进入下一关。

开发环境:
编程语言：Python 3.8 及以上版本
图形库：Pygame 2.6.1
运行系统：Windows 操作系统

安装和运行方法
1、安装 Python 运行环境（推荐 3.8 及以上版本）
2、安装 Pygame 依赖库
3、下载本项目中的 飞箭.py 源码文件
4、进入源码文件所在的文件夹，在地址栏输入 cmd 并回车打开命令行
5、执行命令启动游戏

游戏操作说明：
1、鼠标左键点击箭头：尝试让箭头沿自身方向飞出棋盘
2、路径畅通：箭头沿方向平滑飞出棋盘并消除
3、路径被阻挡：箭头红色闪烁并抖动，同时扣除 1 次失误机会
4、「重新开始」按钮：重置当前关卡，恢复全部失误次数
5、清空本关所有箭头：自动进入下一关
6、失误次数耗尽：进入失败界面，可选择「重新开始本关」或「返回主菜单」
7、全部关卡通关：显示通关结算界面，点击可返回开始界面
